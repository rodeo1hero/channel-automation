Privacy Policy

Channel Automation is a personal-use tool with a single user (its owner and developer). It is not distributed to or used by any other person.

The tool uses the YouTube Data API only to upload videos to its owner's own YouTube channel, on the owner's own behalf. It does not collect, store, or share any data belonging to any other person, and it does not access any YouTube account other than its owner's.

This page collects no visitor data itself (no cookies, no analytics, no tracking).
